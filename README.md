# B题：特殊医学用途配方食品数据分析

2024 年（第 7 届）“泰迪杯”数据分析技能赛 B 题项目。项目围绕 182 款特殊医学用途配方食品，完成营养成分与说明书字段提取、生产概况可视化和基于需求的推荐。

## 目录说明

- `2024年泰迪杯数据分析B题代码/V2版本 第123问完整代码/任务1.ipynb`：任务 1，说明书字段与营养成分提取、分类和注册证号解析。
- `2024年泰迪杯数据分析B题代码/V2版本 第123问完整代码/任务2.ipynb`：任务 2，生产概况可视化。
- `2024年泰迪杯数据分析B题代码/V2版本 第123问完整代码/任务3.ipynb`：任务 3，基于百度文心接口的推荐示例。
- `dataset/`：原始数据与 182 款产品说明书，仅保留在本地，不纳入 GitHub 代码仓库。
- `result/`：任务结果文件。
- `2024年泰迪杯数据分析B题代码/代码运行教程/`：本地运行教程与视频资料。
- `jupyter(1)/`：早期试验笔记本，作为草稿保留，不作为主流程。

## 本地运行

建议在项目根目录启动 Jupyter，并在“V2版本 第123问完整代码”目录中运行笔记本。任务 1、2 需要本地数据文件；任务 3 还需要配置百度 API 环境变量：

```powershell
$env:BAIDU_API_KEY = "your-api-key"
$env:BAIDU_SECRET_KEY = "your-secret-key"
jupyter notebook
```

依赖见 `requirements.txt`。推荐使用虚拟环境安装，不要把 API 密钥写入笔记本或提交到 Git。
